# 子非秋月 · 文案整理站（静态 MVP 原型）

## 如何使用

1. 解压整个文件夹。
2. 双击 `index.html` 即可打开首页（Windows 11 的 Edge / Chrome 均可）。
3. 点击“全部文章”进入文章目录，点击文章标题打开阅读页面。
4. 不需要 npm、不需要安装依赖、不需要数据库、不需要启动服务器。

## 文件结构

- `index.html`：首页（上方导航、左上封面、左下推荐、右侧金句）。
- `articles.html`：文章目录页（按 `published` 时间降序）。
- `read.html`：文章详情页，根据地址中的 `id` 显示正文。
- `style.css`：全部页面的样式、桌面与移动端自适应。
- `data.js`：文章、推荐 ID 与金句内容。
- `main.js`：静态页面内容渲染与页面间跳转。

## 修改内容

直接使用记事本或代码编辑器打开 `data.js`：

- `articles` 数组每一项代表一篇文章。字段：
  - `id`：唯一、简短、不要重复；
  - `title`：文章标题；
  - `published`：原视频发布时间，格式 `YYYY-MM-DD`；
  - `type`：人物独白 / 何为系列（推荐卡片的小字）；
  - `description`：推荐卡片的简介；
  - `sourceUrl`：获准使用时，可填写原始视频链接；
  - `paragraphs`：正文的段落数组，每一段使用一段字符串。
- `featuredIds`：首页推荐的文章 ID，默认 4 篇。
- `quotes`：首页右侧金句文本数组，建议保留 3 条短句。

全部文章列表自动按 `published` 从近到远排列，无需手动排序。

## 重要说明

本原型所有文章正文、日期与金句都是**原创的虚构演示内容**，并非对子非秋月的视频进行的转写，也不代表真实发布日期。首页封面为 CSS 绘制的临时视觉方案，不是原作者原图。

如计划公开发布视频文案全文，请先确认作者对转载的授权；在没有授权时，可先展示自己写的导读、作品索引和来源链接。
