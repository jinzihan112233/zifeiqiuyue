# 子非秋月 · 文案整理（纸本静态 MVP）

淡黄色纸面、少量线描和宋体标题，保留“左侧封面与推荐、右侧摘句”的布局。包含首页、全部文章、纯阅读页；本项目是非官方演示站。

## 如何使用

1. 解压整个文件夹。
2. 双击 `index.html` 即可打开首页（Windows 11 的 Edge / Chrome 均可）。
3. 点击“全部文章”进入文章目录，点击文章标题打开阅读页面。
4. 不需要 npm、不需要安装依赖、不需要数据库、不需要启动服务器。

## 文件结构

- `index.html`：首页（上方导航、左上封面、左下推荐、右侧金句）。
- `articles.html`：文章目录页（按 `published` 时间降序）。
- `read.html`：文章详情页，根据地址中的 `id` 显示正文。
- `style.css`：全部页面的样式、桌面与移动端自适应。
- `data.js`：文章、推荐 ID 与金句内容。
- `main.js`：静态页面内容渲染与页面间跳转。
- `check-data.cjs`：可选的数据自检脚本；有 Node.js 时运行 `node check-data.cjs`。浏览网站无需 Node.js。

桌面端推荐为两列，手机端为单列，摘句顺序移到推荐之后；窄屏导航可自动换行。所有字体均使用系统回退，纸纹与线描由本地样式和 SVG 提供，不依赖网络资源。

桌面项目已初始化为 `main` 分支。第一条提交保存原始原型，之后的提交记录纸本版本；未连接远程仓库。

## 修改内容

直接使用记事本或代码编辑器打开 `data.js`：

- `articles` 数组每一项代表一篇文章。字段：
  - `id`：唯一、简短、不要重复；
  - `title`：文章标题；
  - `published`：原视频发布时间，格式 `YYYY-MM-DD`；
  - `type`：人物独白 / 何为系列（推荐卡片的小字）；
  - `description`：推荐卡片的简介；
  - `sourceUrl`：获准使用时，可填写原始视频链接；
  - `paragraphs`：正文的段落数组，每一段使用一段字符串。
- `featuredIds`：首页推荐的文章 ID，默认 4 篇。
- `quotes`：首页右侧金句文本数组，建议保留 3 条短句。

全部文章列表自动按 `published` 从近到远排列，无需手动排序。

## 重要说明

所有文章正文、标题、日期与摘句都是**虚构演示内容**，并非对子非秋月的视频进行的转写，也不代表真实发布日期。首页文案为站点说明，线描是为本站绘制的装饰，不是原作者的美术素材。

当前演示标识在三页 HTML、`main.js` 和本文档中统一说明；未来替换真实内容时，应核对正文、原视频日期、具体视频来源及标识后一起更新，避免真实内容与演示数据混淆。网页按原视频 `published` 排序；目前该字段仍是示例日期。

如计划公开发布视频文案全文，请先确认作者对转载的授权；在没有授权时，可先展示自己写的导读、作品索引和来源链接。

尚未实现登录、点赞、讨论、在线发布或管理后台；本站不保存访客数据。保留原有数据结构，后续功能按实际需求另行设计。
