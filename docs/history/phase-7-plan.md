# P7 文本批注与版本阅读：实施计划

2026-10-21。依据使用者确认的聊天计划，复用 P6 评论与生命周期，不新增依赖或重写旧快照。

| 步骤 | 目标 | 验证 |
| --- | --- | --- |
| 1 基线 | 备份数据库、媒体和清单；记录已有快照及定位字段哈希 | 开发库及测试库既有定位未变 |
| 2 文本映射 | 固定 v1 文字规则，统一 DOM UTF-16 与码点双向转换 | 中文、emoji、组合字符、跨标签和元素边界往返 |
| 3 创建 | 冻结快照/规则/引用/上下文，服务端复算，事务与防重 | 伪造、越权、锁定和重试用例 |
| 4 高亮 | DOM Range 与浏览器高亮，保留无支持时退化 | 重叠切换不修改原文 DOM，链接与再次选字正常 |
| 5 分页 | 按快照分页及定向查询，加分页索引和定位约束 | 超过 100 条及跨内容/版本拒绝 |
| 6 版本 | 统一版本/批注/根评论链接，提供旧版入口 | 新版插段、删段后旧批注仍准确追溯 |
| 7 回退 | 未知规则、文本不一致、删除、隐藏、下架及清除 | 不猜测定位，不泄露引用，恢复不复活清除数据 |
| 8 验收 | 自动回归、构建、恢复、桌面真实选区及移动真机 | 未测项目单列，真机未验收不勾选 P7-04 |

规则详见 [批注与版本阅读指南](../annotation-guide.md)。文章与帖子沿用现有开放范围；首版只高亮当前选中的一个批注。P8 部署、通知、搜索、点赞、自动重定位及复杂重叠菜单不在范围内。
