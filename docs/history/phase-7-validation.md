# P7 文本批注与版本阅读：实现、教程与验证

实施日期：2026-10-21 至 2026-10-22。本机实现、自动回归与桌面浏览器实测完成；手机真机与 200% 缩放专项仍待验收，不据此将 P7 全阶段标为验收完成。计划见 [P7 计划](phase-7-plan.md)，使用与规范见 [批注指南](../annotation-guide.md)。

## 实际交付

- 保留 `p1-markdown-dom-v1` 的规范文本，未重新渲染或重算既有快照。DOM 文字节点/元素边界与 Unicode 码点双向映射，拒绝截断代理对或跨图片选区。
- 创建时冻结快照、规则版本、范围、引用和上下文；服务端重读冻结快照并复算，继续沿用评论事务、限流、会话复查和请求防重。
- 正文选字后提供入口，点击后才移动到输入框。键盘可通过原文精确查找、上下文和位置明确选择某一处重复句。
- 高亮使用 DOM Range 与 CSS Custom Highlight，支持重叠范围切换，不拆分正文节点；能力不足时用原生选择退化强调。失败显示引用和版本入口，不猜测相似文字。
- 批注每页 20 条，直接读取不依赖当前页，超过原 100 条上限仍可访问。
- 批注、讨论与个人中心链接统一保留稳定版本、批注和根评论目标；批注回复也沿根批注回到原版本。当前版提供其他版本的可见批注入口与计数。
- 取消引用或保存失败保留输入，未发布时离开提醒，可下载含版本/引用/正文的本地草稿。讨论锁定、隐藏、下架、删除与清除继续遵守 P6。

文章与帖子保持现有批注开放范围，没有新增第三套评论模型、依赖或自动重定位。

## 接口与数据约束

| 接口 | 规则 |
| --- | --- |
| `GET /api/community/annotations?content=ID&snapshot=ID&page=页码` | 只读公开快照的可见批注；每页 20 条；页码与内容/快照关系校验 |
| `GET /api/community/annotation-detail?content=ID&snapshot=ID&id=ID` | 定向获取同内容、同快照的可见批注，隐藏/删除/下架均不可读取 |
| `POST /api/community/annotation` | 继续现有路径，HTTP 必须携带渲染版本与前后文；旧标签页缺少依据返回 409，并提示先保留输入 |

响应沿用 `private, no-store`。内部既有调用可以省略客户端规则/上下文字段，但仍由服务端按快照规则重新校验引用与正文一致性；不是绕过权限的接口。

增量迁移 `20261021_153850_annotation_anchors` 新增快照/创建时间分页索引与定位触发器。作者、内容、快照、根评论及起止位置创建后不可改；引用和上下文仅允许在作者删除正文时受控擦除。新定位必须关联同内容快照与同作者顶层评论。

已先在测试库迁移，再应用开发库，重复迁移不重复执行。迁移不新增业务表，不修改旧快照文本、渲染版本或批注位置。回退此迁移仅移除新增约束/索引，不恢复作者删除或敏感清除的文字。
