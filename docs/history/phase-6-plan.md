# P6 评论、回复、举报与管理：实施计划

2026-10-21。根据使用者已确认的聊天计划实施，保持单一应用、数据库与受控媒体，不新增依赖。

| 步骤 | 目标 | 验证 |
| --- | --- | --- |
| 1 基线 | 保留已有修改，备份数据库、媒体及独立清单 | 原文章源文件哈希保持一致 |
| 2 模型 | 评论、举报、讨论锁定、分页索引与关系约束 | 跨内容父级及关系修改失败 |
| 3 批注兼容 | 一条批注对应一条顶层评论，正文唯一来源，原定位保留 | 回填校验正文、作者与内容；旧测试通过 |
| 4 评论生命周期 | 新增、连续回复、编辑修订、删除占位、限流与请求防重 | 越权、竞争、长度和安全 Markdown 用例 |
| 5 举报闭环 | 去重、管理队列、隐藏/恢复、驳回、封禁、审计 | 并发处理仅一个成功，内部资料不公开 |
| 6 父内容联动 | 锁定、下架、清除和清单重放覆盖所有讨论入口 | 直接 ID、个人中心、批注引用和恢复均不能绕过 |
| 7 页面 | 阅读页讨论、批注回复入口、我的评论、管理员举报队列 | 真实浏览器操作，失败保留输入，键盘可达 |
| 8 出口 | 全部回归、显式迁移、生产构建、独立恢复及记录 | 自动验证与人工专项分开记载 |

评论最多 5,000 个 JavaScript 字符单位（UTF-16），与现有 maxlength 一致；纯文本与基础 Markdown，禁图片与原生 HTML。整篇评论跟随内容，批注仍属于原快照。回复关系可以继续深入，界面只有两级缩进。

作者删除擦除正文及该批注引用，保留占位和他人的回复，不允许直接回复占位。管理员隐藏与作者删除独立；编辑不解除隐藏，恢复显示不复活删除正文。隐藏项公开端只提供占位，不提供正文、摘录及其作者私密字段。

锁定保留可见评论，禁止新增评论、回复及批注，仍允许作者编辑、删除和成员举报。内容下架后普通用户不能读取讨论或通过个人中心读取引用；恢复不解锁、不恢复独立隐藏。敏感清除覆盖举报、审计中的自由文字，清单重放同样处理新集合。

发言额度由评论、回复、批注共享：每账号每分钟 5 条、北京时间自然日 200 条；本机共享 IP 桶每分钟 60 条、自然日 2,000 条。举报每账号每分钟 5 次、滚动 24 小时 30 次，本机共享 IP 每分钟 60 次。公网可信代理留到部署阶段。

P7 定位算法与高亮改进、通知、点赞、搜索、公众部署不在本次范围内。不自动提交、推送或发布。
