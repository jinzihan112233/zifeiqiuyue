# 2026-10-22 本机部署准备

这是部署准备记录，正式网站尚未公网开放。当前操作说明见 [本机公网部署](../local-deployment.md)。

## 已完成

- 单独生产库、恢复库和应用/迁移角色；应用角色无数据库管理或创建表的权限，也不能连接生产恢复库。重复准备与迁移不重置秘密或重复执行迁移。
- 生产配置显式加载，开发、测试、生产数据库及构建目录分开；生产运行进程不载入迁移和测试库凭据。
- 登录、注册、恢复、评论、批注、举报、上传使用可信 Cloudflare 访客 IP，并保留账号限流。未配置代理的本机模式不信任客户端转发头。
- 上传增加累计媒体预算、频率与磁盘余量检查，保留原有格式、像素、文件大小、不可变媒体及权限校验。
- 基础安全响应头，生产 HTTPS 配置失败时拒绝启动；未将当前 CSP 宣称为完整脚本策略。
- 生产库迁移、独立生产构建、四个回环页面及响应头检查；缺少可信代理 IP 的生产写请求被拒绝。
- 空生产库备份及独立恢复演练，验证表记录数、媒体哈希、引用和恢复库写入。没有将其当作真实生产数据的完整灾难恢复。
- 临时无数据测试页经 Cloudflare Tunnel 返回 200，维护者使用大陆手机网络确认可迅速打开；这仅验证当时网络，不保证长期可用性。
